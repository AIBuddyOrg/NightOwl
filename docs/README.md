# NightOwl – School-Parent Communication Agent

This repository contains the architecture and delivery groundwork for a secure, multi-channel AI communication platform for schools.

## Documents

- `docs/system-architecture.md` – End-to-end platform architecture and component design.
- `docs/world-state-boundaries.md` – Agent world-state model, authority boundaries, and escalation rules.
- `docs/security-privacy-blueprint.md` – Security controls for student data and compliance strategy.
- `docs/implementation-roadmap.md` – Delivery phases, milestones, and operational setup.

## Goals

1. Enable two-way communication with parents over WhatsApp.
2. Let each school choose its preferred LLM provider/model.
3. Ensure safe handling of student data with strict boundary controls.
4. Route unknown or sensitive questions to class teachers or communication admins.
5. Allow teachers to provide rough instructions; agent drafts formal messages for approval and publication.
